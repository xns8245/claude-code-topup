### KYC 风控，代充方管不了

Anthropic 会针对个别账号独立触发身份验证（KYC）。这件事和这次升级没有直接关系——何时触发、哪些账号触发，完全由官方风控决定，代充服务无法预知也无法干预。

一旦触发，需要账号本人持政府颁发的实体证件，按官方流程完成验证，任何第三方都代办不了。

### 充值成功后基本退不回来

钱一旦付给 Claude 官方，代充方同样收不回这笔款。所以后续如果触发 KYC、或因未完成验证导致账号无法使用，都不算充值失败，不能以此申请退款。部分服务商支持充值码未使用时退款，下单前把售后条款逐条看清。
